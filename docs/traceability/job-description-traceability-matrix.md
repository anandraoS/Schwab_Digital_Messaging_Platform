# Job-Description Traceability Matrix

**Scope and honesty statement.** This is an independent reference implementation built from a publicly stated job description for a senior full-stack messaging engineer. It is **not** any employer's internal system, uses only synthetic data, dummy credentials and simulated providers, and reproduces no proprietary design. Each row points to real files, classes, tests or scripts (verified against the working tree when this matrix was written) or is labelled "Conceptual artifact (document only)". A document existing is not claimed as a skill. Test **counts and pass/fail results are deliberately not stated here**: the only place executed results are recorded is `docs/validation/VALIDATION_REPORT.md`; anything not executed there (Docker, Kubernetes, Helm, Cloud Foundry, k6, Testcontainers, CI pipelines, real PostgreSQL/Oracle/RabbitMQ/Redis/MongoDB) must be treated as not executed. Class names in the evidence column are Java test classes under `backend/src/test/java/com/example/messaging/`.

Machine-readable copy: `job-description-traceability-matrix.csv` (same columns, same rows).

Maintenance rule: when a class or test is renamed, update this file and the CSV; `docs/design/CONSISTENCY_LOG.md` records the last consistency pass.
