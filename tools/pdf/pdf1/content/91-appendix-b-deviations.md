# Appendix B. Implemented Deviations from the Contract

The build contract (`docs/design/CONTRACT.md`) was the single source of truth during construction. Wherever the implementation had to differ, the difference was appended to `docs/design/DEVIATIONS.md` instead of silently changing shared decisions. The file is **append only** and is the authoritative record of implemented behaviour. It is reproduced here exactly as written in the repository, including its terse style, because the main chapters of this PDF rely on it.
