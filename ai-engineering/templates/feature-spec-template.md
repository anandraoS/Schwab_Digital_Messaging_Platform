# Feature Spec Template (pointer)

The canonical template is `specs/spec-template.md`. Copy it to `specs/NNNN-short-name.md`, fill every section, and keep the status header current (Draft, Review, Approved, Implemented, Superseded).

Minimum sections: Context and problem, Goals/non-goals, Requirements (numbered), Acceptance criteria (Given/When/Then), Design (with ADR links), Data/API/config changes, Failure modes, Security and privacy, Performance, Observability, Test plan (named tests), Task decomposition, Rollout and rollback, Documentation updates, Open questions.

Why a pointer: one template, no duplicated copies to drift (`context-engineering.md`).
